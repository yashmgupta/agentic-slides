# Open-source presentation-generation landscape

**Research snapshot:** 2026-11-02. Repository stars, license identifiers, and `updated_at` values below were queried from GitHub's public repository API on that date. `updated_at` is repository metadata, not proof of a recent source-code change. Counts can change. Feature/model/stack descriptions are from repository descriptions and linked documentation; where not established in the inspected source, they are explicitly marked as unknown. Search discovery is not proof that a finished deck was AI-generated.

## Search method and scope

Discovery used GitHub repository search across “AI presentation generator,” “LLM PowerPoint,” “presentation skill,” “PPTX presentation generator,” and related terms, then direct repository metadata and README/skill inspection. The broad `AI presentation generator` query returned **675 matching repository results** at query time (not a count of distinct repos inspected). **30 distinct candidates are catalogued here**. Ten received deeper README/skill review (listed in [deep-analysis.md](deep-analysis.md)); the other 20 are discovery candidates whose technical details are limited to public repository descriptions and README-level evidence. GitHub code search, issue/discussion histories, commit-level prompt archaeology, and broad external search-engine coverage were not completed. This is a bounded first landscape, not an exhaustive audit of every hit.

Classifications: **A** = evidence of AI-assisted creation of an included sample/product is documented; **B** = AI is a feature of the product that creates presentations; **C** = reusable prompts/skills/tooling that could create presentations. A project may fit more than one class. Most projects are **B or C**; their existence does not establish that the repository's software or sample output was generated by AI.

## Evidence classes and limits

- **A (AI-assisted repository/sample creation):** No general “the whole project was generated by AI” conclusion is established from these searches. A showcase created by a product is not proof that the generator itself was written by AI.
- **B (AI used by product):** Examples include Presenton, Presentation Forge, ppt-agent, and the Gemini-backed API. The AI integration describes runtime behavior, not authorship of the software.
- **C (prompts/skills):** The explicitly named skill and prompt repositories expose reusable instructions; installation instructions are platform-specific and should not be treated as universal.
- This landscape has no independently rerun quality benchmark. Star counts are discovery context, not quality scores.
- Repository metadata and source documentation are not a license audit. Never copy a prompt, font, screenshot, sample deck, or asset without checking its own rights.
