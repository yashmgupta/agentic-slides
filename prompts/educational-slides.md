# Prompt: beginner-friendly educational slides

Use the [master prompt](master-presentation-prompt.md) contract. Create an 8-slide introduction to the topic supplied by the user.

Start with a motivating question and a plain-language definition. Build one concept at a time; include a worked example or process, address a common misconception, add a short recap, and finish with one learner action. Define jargon on first use and move caveats into notes. Distinguish simplified teaching models from technically complete descriptions. Do not create citations, quotations, or facts that were not supplied or independently verified.
