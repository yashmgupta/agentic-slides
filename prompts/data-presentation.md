# Prompt: source-grounded data presentation

Use the [master prompt](master-presentation-prompt.md) contract. Create a 6-slide analytical readout from the supplied data:

1. Title and reporting period.
2. Data scope, definitions, and source.
3. Main chart using the exact supplied categories and values.
4. Comparison or segment view only where supported.
5. Interpretation, separating observation from explanation.
6. Decision, caveat, or next analysis.

Never infer causation from a trend alone. Preserve units, date ranges, denominators, and missing-data caveats. Use a chart slide only when the specification format can represent the supplied data faithfully; otherwise explain the limitation in notes and use bullets.
